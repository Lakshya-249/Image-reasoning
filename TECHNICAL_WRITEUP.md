# Technical Write-Up – Image-Aware Reasoning Assistant

## Overview

This project implements a **Mini Multimodal Intelligence System** that evaluates whether an image is suitable for professional use (e.g., e-commerce or marketing).  
The system is intentionally designed to separate **visual understanding** from **reasoning**, ensuring that decisions are grounded in extracted signals rather than raw pixels.

The goal of the system is to demonstrate **ML fundamentals, engineering judgment, explainability, and trade-off awareness**, rather than UI or deployment polish.

---

## System Architecture

```
Input Image
↓
Pre-LLM Feature Extraction
├── Object Detection (YOLOv8)
├── OCR (Tesseract)
└── Image Quality Heuristics
├── Blur Detection
└── Brightness Estimation
↓
Structured Feature Payload (JSON)
↓
LLM-Based Reasoning (Groq – LLaMA 3.1)
↓
Structured Decision Output (JSON)
↓
Persisted Output (utils/output/\*.json)
```

### Key Architectural Principle

> **The LLM never receives the raw image.**  
> All reasoning is performed over extracted, structured features to reduce hallucination risk and improve explainability.

---

## Feature Extraction Layer (Pre-LLM Intelligence)

### Object Detection

- Implemented using **YOLOv8 (nano variant)**.
- Detects semantic elements such as objects, people, or hands.
- Useful for identifying non-professional artifacts (e.g., human presence in product images).

**Trade-off:**  
YOLOv8n was chosen for speed and low latency over maximum accuracy, making it suitable for real-time or batch inference.

---

### OCR (Text Detection)

- Implemented using **Tesseract OCR**.
- Detects overlaid text, watermarks, or promotional banners.
- Text presence is often a negative signal for professional product images.

**Trade-off:**  
OCR accuracy depends on image quality, but provides high-value semantic information at minimal computational cost.

---

### Image Quality Heuristics

- **Blur detection** using Laplacian variance.
- **Brightness estimation** using grayscale intensity.
- Simple, classical computer vision techniques.

**Rationale:**  
Classical heuristics are fast, interpretable, and sufficient for identifying common quality issues.

---

## Reasoning Layer (LLM)

The reasoning layer consumes **only structured features**, never raw pixels.

- Implemented using **Groq’s LLaMA 3.1 (70B)** model.
- Produces a **strictly structured JSON output**:
  - `image_quality_score`
  - `issues_detected`
  - `final_verdict`
  - `reasoning_summary`
  - `confidence`

**Why an LLM here?**

- Combines multiple weak signals into a holistic judgment
- Encodes domain-level reasoning (professionalism, trust, suitability)
- Keeps logic flexible and easily extensible

The reasoning module is **vendor-agnostic** and can be replaced with another LLM or a deterministic engine without changes to the vision pipeline.

---

## Output Persistence

Each analysis run produces a JSON file stored in:

```
src/utils/output/<image_name>.json
```

Each output contains:

- Source image path
- Timestamp
- Extracted features
- Final decision and confidence

This enables:

- Offline analysis
- Auditing and inspection
- Dataset iteration and benchmarking

---

## Limitations

- No background segmentation or aesthetic scoring
- OCR accuracy varies with lighting and resolution
- LLM outputs may vary slightly across runs
- No batching, caching, or async execution implemented

---

## Future Improvements

- Batch inference for large datasets
- PDF and multi-page document support
- Confidence calibration across multiple signals
- Model comparison and ensemble scoring
- Queue-based async processing for scalability

---

## Productionization Strategy

In a production environment, this system would be deployed as:

- A **stateless inference service**
- Feature extraction and reasoning decoupled
- Batched inference for throughput optimization
- Secrets managed via environment variables or a secret manager
- Monitoring on:
  - Inference latency
  - Confidence distributions
  - Failure and edge cases

The current architecture already supports this with minimal changes.
